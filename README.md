One line, at most 120 characters: the error message a kitchen toaster shows its owner when something goes wrong. Entry for make.fun's "The Funniest Toaster Error Message" bounty.

The program writes a single error line to `/output/entry.txt`:

> ERROR: I toasted your bread twice. It asked me to stop. I cannot stop. I am a toaster.

## Run it

```sh
python3 main.py
```
